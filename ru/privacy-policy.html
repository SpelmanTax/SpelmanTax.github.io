Политика конфиденциальности — SpelmanTax

Настоящая политика описывает, как SpelmanTax обрабатывает персональные данные в соответствии с Регламентом (ЕС) 2016/679 (GDPR) и действующим итальянским законодательством.

Ответственный за обработку данных: SpelmanTax — Д‑р Галья Спельман, Viale Druso 2, 39100 Болцано. E‑mail: info@spelmantax.com

1. Категории обрабатываемых данных

SpelmanTax обрабатывает только те данные, которые необходимы для связи с пользователями и технической работы сайта.

Данные, предоставленные добровольно: имя, адрес электронной почты, номер телефона, содержание сообщений, отправленных по e‑mail или WhatsApp.

Технические данные, собираемые автоматически:

  • IP‑адрес
  • информация о браузере и операционной системе
  • технические журналы (лог‑файлы), создаваемые GitHub Pages

Технические данные используются исключительно для безопасности, функционирования сайта и мониторинга системы.

2. Цели обработки данных

Данные обрабатываются для следующих целей:

  • ответы на запросы, отправленные через сайт, e‑mail или WhatsApp
  • коммуникация с клиентами и заинтересованными пользователями
  • выполнение юридических обязательств, связанных с профессиональной деятельностью
  • обеспечение IT‑безопасности и корректной работы сайта
  • технический мониторинг без профилирования

Профилирование и агрессивный маркетинг не осуществляются.

3. Правовые основания

Обработка данных осуществляется на основании:

  • ст. 6, п. 1, лит. b GDPR — выполнение предварительных действий и обработка запросов пользователей
  • ст. 6, п. 1, лит. c GDPR — выполнение юридических обязательств
  • ст. 6, п. 1, лит. f GDPR — законный интерес (безопасность, предотвращение злоупотреблений, техническое управление)

4. Получатели данных

Персональные данные могут передаваться только техническим поставщикам услуг:

  • Google LLC — управление электронной почтой (Gmail).
  • GitHub, Inc. / Microsoft Corporation — хостинг сайта через GitHub Pages.

Поставщики обрабатывают данные только в рамках технической поддержки и обязаны соблюдать конфиденциальность.

5. Передача данных за пределы ЕС

Некоторые поставщики (Google и GitHub/Microsoft) могут передавать данные в США. Передача осуществляется на основании Стандартных договорных условий (SCC), утверждённых Европейской комиссией.

SpelmanTax использует только поставщиков, соответствующих требованиям GDPR.

6. Срок хранения данных

  • Электронные письма и коммуникации: хранятся 24 месяца.
  • Технические журналы: управляются согласно политике GitHub/Microsoft.

Данные хранятся только столько, сколько необходимо для указанных целей.

7. Права субъекта данных

Пользователь имеет право:

  • на доступ к данным
  • на исправление
  • на удаление
  • на ограничение обработки
  • на возражение
  • на подачу жалобы в надзорный орган

Запросы можно отправлять на: info@spelmantax.com

8. Cookie‑файлы

Сайт использует только технические cookie‑файлы, необходимые для его работы. Cookie‑файлы для профилирования, маркетинга или аналитики не используются.

Отсутствует любое отслеживание через Google Analytics.

Пользователь может управлять cookie‑файлами через настройки браузера.

9. Безопасность

SpelmanTax применяет технические и организационные меры для защиты персональных данных: системы безопасности, контроль доступа и постоянный мониторинг.

Технические платформы, используемые SpelmanTax (Google Workspace, Gmail, GitHub Pages), сертифицированы по международным стандартам безопасности, включая ISO/IEC 27001. Это обеспечивает защищённую инфраструктуру и безопасную обработку данных.

Сайт может содержать ссылки на внешние ресурсы. SpelmanTax не несёт ответственности за обработку данных на сторонних сайтах.
