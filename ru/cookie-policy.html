Политика использования Cookie‑файлов

Этот сайт использует только технические cookie‑файлы, необходимые для его работы. Cookie‑файлы для профилирования, маркетинга или аналитики не применяются.

1. Технические cookie‑файлы

Технические cookie‑файлы обеспечивают базовые функции сайта, включая безопасность и управление сервером.

2. Cookie‑файлы, используемые на сайте

  • Cookie‑файлы сессии — необходимы для работы сайта.
  • Cookie‑файлы GitHub Pages — используются только для безопасности и технического управления.

Google Analytics не используется.

3. Управление cookie‑файлами

Пользователь может управлять cookie‑файлами через настройки браузера.

4. Обновления

Настоящая политика может обновляться. Актуальная версия всегда доступна на этой странице.
